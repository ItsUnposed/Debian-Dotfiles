# dotfiles

i3 + rofi + xfce4-panel Setup

## Wiederherstellen

    git clone git@github.com:ItsUnposed/dotfiles.git ~/dotfiles
    ln -s ~/dotfiles/i3 ~/.config/i3
    ln -s ~/dotfiles/rofi ~/.config/rofi
    ln -s ~/dotfiles/.bashrc ~/.bashrc
    sudo cp ~/dotfiles/system/deumlaut /usr/share/X11/xkb/symbols/
    cp ~/dotfiles/wallpaper/Kali-Background.jpeg ~/Pictures/
